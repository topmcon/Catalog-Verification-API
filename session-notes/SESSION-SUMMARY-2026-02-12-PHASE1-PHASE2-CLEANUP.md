## Architecture Changes

### Alias Loading Flow (After Phase 2)

```
CATEGORY_ALIASES (canonical → aliases mapping)
├── Defined in: src/config/category-aliases.ts (246 lines)
├── Re-exported via: src/config/constants.ts as CATEGORY_NAME_ALIASES
└── Available via: src/config/index.ts exports

AI_CATEGORY_ALIASES (type variations → canonical)
├── Defined in: src/config/constants.ts (lines 148-190)
├── Regenerated by: scripts/regenerate-hardcoded-lists.js
└── Available via: src/config/index.ts exports

DEPARTMENT_CATEGORIES (dept → categories mapping)
├── Hardcoded in: src/services/category-matcher.service.ts
├── Regenerated by: scripts/regenerate-hardcoded-lists.js
└── Synced from: categories.json

DEPARTMENTS (official department list)
├── Loaded from: src/config/salesforce-picklists/departments.json
├── Via: src/picklist-master/04-departments-families/department-family-config.ts
└── NO hardcoding - pure JSON loading
```
