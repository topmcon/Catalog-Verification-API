### Why Bad Measurements Happen:

**Root Cause #1: Multiple Dimensions Available**
- Products have: Height, Width, Depth, Trim Size, Cutout Size, Overall Dimensions, Box Dimensions
- AI may grab the wrong one (e.g., fixture arm width instead of overall height)
- **Example**: Item 7 grabbed 4.5" (arm width?) instead of 24" (height)

**Root Cause #2: Conflicting Sources**
- Salesforce manual title: Sometimes wrong (Item 5 "9" Palm Leaf Vase" for a 44" bath bar!)
- Ferguson title: Usually correct but abbreviated
- Web Retailer: May have different measurement standards
- Spec sheets: Very precise (9.0625") but sometimes incomplete
- **AI picks the wrong source or averages conflicting data**

**Root Cause #3: Measurement Type Confusion**
- Recessed lighting has: Cutout diameter, Trim diameter, Housing depth
- Wall sconces have: Height, Width, Extension from wall
- Bath bars have: Overall width, per-light spacing
- **AI doesn't know which dimension is most relevant for titles**

**Root Cause #4: Data Entry Errors**
- Salesforce manual titles contain typos or wrong products
- Ferguson may have spec sheet errors
- **AI trusts bad data**

### Why Wrong Light Counts Happen:

**Root Cause #1: Salesforce Data is Wrong**
- **Example**: Item 22 - SF says "1-Light", Ferguson says "2 Light"
- AI trusts SF manual data which contains errors
- **Solution**: Validate against multiple sources, prefer Ferguson/Web Retailer

**Root Cause #2: Integrated LED Confusion**
- Modern LED fixtures have one "light source" (integrated LED strip)
- But may have multiple "light elements" visually
- Example: 2-light bath bar with integrated LED = is it "1-Light LED" or "2-Light LED"?
- **Manufacturers inconsistent in how they count this**

**Root Cause #3: Model Number Parsing**
- Some model numbers encode light count: "2220-BN" might mean 2-light, 20-inch
- AI may parse model incorrectly
- Or product line changed and model encoding is obsolete

**Root Cause #4: Missing Data**
- Ferguson often omits light count for single-source LEDs
- AI must infer from other clues
- **May infer wrong count when data sparse**

## Recommended Fixes

### Fix #1: LED Detection Enhancement
```typescript
function detectLED(modelNumber: string, fergusonTitle: string, webRetailerTitle: string): string {
  // Check model number patterns
  if (/-LED$/i.test(modelNumber)) return 'LED';
  if (/-LL$/i.test(modelNumber)) return 'LED'; // LED Light suffix
  if (/LED\d{3,4}/i.test(modelNumber)) {
    const temp = modelNumber.match(/LED(\d{3,4})/i);
    if (temp) {
      const kelvin = temp[1];
      if (kelvin === '927' || kelvin === '930') return '3000K LED';
      if (kelvin === '940' || kelvin === '941') return '4000K LED';
      return 'LED';
    }
  }
  
  // Check titles
  if (/integrated\s+led/i.test(fergusonTitle)) return 'Integrated LED';
  if (/\d{4}K\s+LED/i.test(fergusonTitle)) {
    const match = fergusonTitle.match(/(\d{4})K\s+LED/i);
    return match ? `${match[1]}K LED` : 'LED';
  }
  if (/\bLED\b/i.test(fergusonTitle)) return 'LED';
  if (/with LED bulb/i.test(fergusonTitle)) return 'LED';
  
  return '';
}
```

### Fix #2: Dimension Validation
```typescript
function selectPrimaryDimension(dimensions: any[], category: string): string {
  // For bath bars, vanities, wall sconces - prefer height or width (largest)
  // For recessed lighting - prefer trim diameter over cutout
  // Validate dimension makes sense for product type
  
  const sorted = dimensions
    .filter(d => d.value > 3 && d.value < 100) // Reasonable range for lighting
    .sort((a, b) => b.value - a.value);
  
  if (category.includes('Bath Bar') || category.includes('Vanity')) {
    // Prefer the larger dimension (usually width for bath bars)
    return sorted[0];
  }
  
  if (category.includes('Recessed')) {
    // Look for trim size specifically
    const trimSize = dimensions.find(d => d.label?.includes('trim'));
    return trimSize || sorted[0];
  }
  
  // Default to largest reasonable dimension
  return sorted[0];
}
```

### Fix #3: Light Count Validation
```typescript
function validateLightCount(aiCount: number, fergusonTitle: string, sfTitle: string): number {
  // Prefer Ferguson over SF if available
  const fergusonMatch = fergusonTitle.match(/(\d+)\s+Light/i);
  if (fergusonMatch) return parseInt(fergusonMatch[1]);
  
  // Check SF title
  const sfMatch = sfTitle.match(/(\d+)[- ]Light/i);
  if (sfMatch) return parseInt(sfMatch[1]);
  
  // If integrated LED and no count specified, default to 1
  if (/integrated\s+led/i.test(fergusonTitle)) return 1;
  
  return aiCount; // Keep AI's inference
}
```
